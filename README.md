# Data Structures & Algorithms Lab — Sem 2

All the DSA lab programs I wrote during my second semester. Putting this up mostly to track my own progress, and maybe help someone else who's going through the same stuff (im sorry man, i feel your pain).

---

## What's in here

**Lab 1**
This lab was just like a basic quick revision of arrays which we already learnt in Sem 1. So this was just a refresher, however the frequency code was definitely something.

**Lab 2**
Now like Lab 1 was a revision of arrays, Lab 2 was a revision of structures, which again we had already learnt in Sem 1. The assignment was a fun program to work on tho.

**Lab 3**
Now this Lab was where the things started getting interesting. Working with pointers in C is... well, definitely a pain. But with these questions, I was able to learn how I can handle pointers, which came in VERY handy later on.

**Lab 4**
This was all about Queues. A fun data structure in my opinion, basically the opposite of a stack, FIFO and all that. Nothing too crazy, but it did lay the groundwork for a lot of things that came after.

**Lab 5**
Oh who doesn't like stacks am I right? This was the easiest and also the most Fun Lab of all i guess. (It's also because I've already worked with stacks in Python in class 11 and 12 so yeah)

**Lab 6**
This one was really fun as well! I already loved doing the prefix postfix expression conversions in theory classes, and when we got to know how we can apply the same in code, it was a great experience.

**Lab 7**
I never knew I would find some data structure THIS fun and interesting to work with until I encountered Linked Lists! It was such an amazing ride, the circular ones and doubly linked lists, everything was so fun to work with and build logic for. This might be one of my most favourite labs that I worked on.

**Lab 8**
Oh, trees. This Lab did hit me hard in the beginning to be honest, it was completely new and also VERY pointer heavy... but eventually I got a hold of it, and all in all a pretty good Lab! Definitely would be using trees in the future for some projects i suppose.

**Lab 9**
Searching and Sorting... Oh what even are we without these? Haha, this was definitely one of the most practically helpful labs in the course tbh, because i honestly do see myself using atleast one of these sorting and searching techniques for most of the projects I plan to make in the future. So definitely a great Lab!

**Lab 10**
Graphs were an interesting curve ball as well! After Binary Trees, i felt graphs were a little bit easier for me, just becuase... I don't know, maybe it was more logical to me that trees. This was a fun one as well! Really enjoyed it.

**PERSONAL PROJECT**
_Task Manager_
I never knew I'd be able to implement something THIS big. I mean if I had to go back in time and tell the Dhwanit from the beginning of Sem 2 that he wrote a 500+ line program, IN C, he would probably laugh to his death lol. But yeah, sure was a fun experience writing this! It was really simple with the structs and everything, and obviously with the easiest linear search it was easy to do the searching part.
